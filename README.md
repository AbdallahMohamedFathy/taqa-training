# نظام تقييم البرامج التدريبية

تحويل نموذج **Training Program Evaluation Form** الورقي لتطبيق ويب:
الـ HR بيبعت **لينك واحد ثابت**، المتدرب يملأ التقييم من موبايله (بيكتب اسم
الدورة وتاريخها والمدربين بنفسه زي الورقة)، والدورات بتتكوّن لوحدها في
الداشبورد مع المتوسطات.

البنية: Next.js 16 (App Router) + TypeScript + Tailwind 4 + Supabase.

---

## خطوات التشغيل

### 1. إنشاء مشروع Supabase

1. اعمل مشروع مجاني على [supabase.com](https://supabase.com).
2. من **SQL Editor → New query**: الصق محتوى
   [`supabase/migrations/0001_init.sql`](supabase/migrations/0001_init.sql)
   واضغط Run. ده بيعمل الجدول وسياسات الأمان (RLS).
3. من **Authentication → Users → Add user**: اعمل حساب لكل موظف HR
   (إيميل + باسورد). مفيش صفحة تسجيل عامة — الحسابات بتتعمل من هنا بس.

### 2. ربط المشروع

انسخ `.env.local.example` لـ `.env.local` واملأه من
**Project Settings → API** في Supabase:

```
NEXT_PUBLIC_SUPABASE_URL=https://your-project-ref.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=your-anon-public-key
```

### 3. التشغيل محلياً

```bash
npm install
npm run dev
```

## طريقة الاستخدام

| الخطوة | المكان |
|---|---|
| الـ HR ينسخ اللينك | `/dashboard` ← **نسخ اللينك** (مرة واحدة للأبد) |
| المتدرب يملأ التقييم | `/evaluate` — من غير تسجيل دخول |
| متابعة النتائج | `/dashboard` ← اختر الدورة: متوسط عام، متوسط كل محور، تفاصيل البنود، التوصيات |
| تصدير البيانات | **تصدير Excel** — من `/dashboard` (ملخص كل الدورات + كل الردود) أو من صفحة دورة واحدة |
| تغيير اللغة | زرار **English / العربية** فوق في كل صفحة |

الـ HR **مش محتاج يعمل حاجة قبل الدورة** — الدورات بتظهر في الداشبورد أول ما
أول متدرب يبعت تقييم.

## إزاي الدورات بتتجمّع

المتدرب بيكتب اسم الدورة بإيده، فنفس الدورة بتوصل مكتوبة بصيغ مختلفة.
[`programKey()`](lib/program-key.ts) بيوحّد الاختلافات اللي بتحصل فعلاً في
الكتابة العربية قبل التجميع:

| اللي المتدرب كتبه | بعد التوحيد |
|---|---|
| السلامة المهنية | السلامه المهنيه |
| السلامه المهنيه | السلامه المهنيه |
| السلامة&nbsp;&nbsp;المهنية (مسافتين) | السلامه المهنيه |
| أساسيات Excel | اساسيات excel |

بيتعامل مع: `ة/ه` · `أ/إ/آ/ا` · `ى/ي` · `ؤ/ئ/ء` · التشكيل والتطويل ·
المسافات الزيادة · حالة الحروف اللاتينية.

**مش بيتعامل مع** اختلاف حقيقي في الاسم (زي "دورة السلامة المهنية" مقابل
"السلامة المهنية") — دول هيفضلوا دورتين. لو ده حصل، صفحة الدورة بتنبّه إن فيه
صيغ مختلفة اتجمّعت، وجدول الردود بيعرض اللي كل متدرب كتبه.

## ملاحظات أمنية

- الردود **مايقدرش حد يقراها** غير المستخدمين المسجلين. المتدرب يقدر يضيف رد
  بس، مش يشوف ردود غيره.
- الفورم مفتوح لأي حد معاه اللينك (زيّه زي النموذج الورقي)، ومفيش منع
  للإرسال المتكرر.

## اللغة

الواجهة عربي/إنجليزي. اللغة بتتخزن في كوكي، فالسيرفر بيرسم الاتجاه الصحيح
(`rtl` أو `ltr`) من أول مرة من غير ما الصفحة تنطّ بعد التحميل.

بنود التقييم بتفضل **ظاهرة باللغتين** في الحالتين — زي النموذج الورقي بالظبط —
بس اللغة المختارة بتبقى هي الأساسية والتانية تحتها بخط أصغر.

لإضافة نص جديد: ضيفه في [`lib/i18n.ts`](lib/i18n.ts) في القاموسين. TypeScript
هيرفض البناء لو نسيت واحد منهم.

## التصدير

`تصدير Excel` بيطلع ملف **.xlsx** (مش CSV) — عشان:
- الـheaders بلون أزرق وخط أبيض عريض، وCSV نص خام مالوش تنسيق
- العربي بيتقري صح على طول، من غير حيلة BOM اللي CSV بيحتاجها

من `/dashboard` الملف بيطلع بورقتين: **ملخص الدورات** (صف لكل دورة بمتوسطات
المحاور) و**كل الردود** (صف لكل متدرب بكل البنود). من صفحة دورة واحدة بيطلع
بورقة واحدة لردودها.
